# Tapping Game App

A simple and fun tapping game built using Flutter and Dart.

## Features

- Tap to increase score
- Real-time score tracking
- Timer-based gameplay
- Game Over screen
- Restart game option
- Smooth and responsive UI

## Technologies Used

- Flutter
- Dart

## How to Play

1. Start the game.
2. Tap the button or screen as fast as possible.
3. Earn points for each tap.
4. Try to achieve the highest score before the timer ends.
